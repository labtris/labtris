## What this is

Labtris exposes an **AWS-compatible API** at `/_aws/` on the same port
your API runs on. Any tool that talks to AWS — the `aws` CLI, boto3,
the Terraform AWS provider, the Pulumi AWS provider, Ansible AWS
modules — works against Labtris with an endpoint override.

Unlike LocalStack, the resources aren't metadata rows in a database:
`RunInstances` boots a **real** QEMU KVM guest, `CreateVpc` allocates
a **real** Linux bridge, `authorize-security-group-ingress` compiles
into a **real** VyOS firewall rule on a **real** vendor firewall you
picked. Same API surface, real behavior underneath.

## Point the AWS CLI at Labtris

```bash
export AWS_ACCESS_KEY_ID=test               # any value works
export AWS_SECRET_ACCESS_KEY=test           # any value works
export AWS_DEFAULT_REGION=labtris-1

# One-shot per service:
aws --endpoint-url https://labtris.local/_aws/sts sts get-caller-identity
aws --endpoint-url https://labtris.local/_aws/ec2 ec2 describe-instances
aws --endpoint-url https://labtris.local/_aws/iam iam list-users
```

To make the endpoint global, use the AWS_ENDPOINT_URL_* envs (aws CLI
≥ 2.13):

```bash
export AWS_ENDPOINT_URL_STS=https://labtris.local/_aws/sts
export AWS_ENDPOINT_URL_EC2=https://labtris.local/_aws/ec2
export AWS_ENDPOINT_URL_IAM=https://labtris.local/_aws/iam
aws sts get-caller-identity   # no --endpoint-url needed
```

Or a global override (aws CLI ≥ 2.15):

```bash
export AWS_ENDPOINT_URL=https://labtris.local/_aws
```

## Auth

Two ways to authenticate:

**1. LocalStack-style (default)**: any Access Key ID / Secret Access
Key works. Labtris will map you to the first admin user. Simplest for
dev.

**2. Real Labtris JWT**: pass your session JWT in a header, so multi-
user setups authenticate correctly:

```bash
export AWS_ACCESS_KEY_ID=test
export AWS_SECRET_ACCESS_KEY=test

aws --endpoint-url https://labtris.local/_aws/sts \
    --cli-input-json '{}' \
    --no-sign-request \
    sts get-caller-identity \
    2>/dev/null || true

# For SDK-level auth, set the header via boto3 event system:
python <<'PY'
import boto3
from botocore.awsrequest import AWSRequest

sess = boto3.Session(aws_access_key_id="test", aws_secret_access_key="test",
                     region_name="labtris-1")
client = sess.client("sts", endpoint_url="https://labtris.local/_aws/sts")

def add_labtris_token(request, **_kwargs):
    request.headers["X-Labtris-Token"] = "eyJ...<your JWT>..."

client.meta.events.register("before-sign.*.*", add_labtris_token)
print(client.get_caller_identity())
PY
```

## Terraform

Point the standard `hashicorp/aws` provider at Labtris:

```hcl
terraform {
  required_providers {
    aws = { source = "hashicorp/aws", version = "~> 5.0" }
  }
}

provider "aws" {
  access_key                  = "test"
  secret_key                  = "test"
  region                      = "labtris-1"
  skip_credentials_validation = true
  skip_metadata_api_check     = true
  skip_requesting_account_id  = true
  s3_use_path_style           = true

  endpoints {
    ec2 = "https://labtris.local/_aws/ec2"
    iam = "https://labtris.local/_aws/iam"
    sts = "https://labtris.local/_aws/sts"
    # As more services ship in L2/L3, add entries here.
  }
}

resource "aws_instance" "gateway" {
  ami           = "ami-labtrisfrrimage00"  # from `aws ec2 describe-images`
  instance_type = "t3.small"
  tags          = { Name = "gateway" }
}
```

Then:

```bash
terraform init
terraform apply
```

**A real Labtris node boots**. Not a fake — a KVM guest with a real
kernel, real interfaces on a real Linux bridge.

## Pulumi

```python
import pulumi
import pulumi_aws as aws

provider = aws.Provider("labtris",
    access_key="test",
    secret_key="test",
    region="labtris-1",
    skip_credentials_validation=True,
    skip_metadata_api_check=True,
    skip_requesting_account_id=True,
    endpoints=[aws.ProviderEndpointArgs(
        ec2="https://labtris.local/_aws/ec2",
        iam="https://labtris.local/_aws/iam",
        sts="https://labtris.local/_aws/sts",
    )])

gateway = aws.ec2.Instance("gateway",
    ami="ami-labtrisfrrimage00",
    instance_type="t3.small",
    opts=pulumi.ResourceOptions(provider=provider))
```

## Non-goals

- **100% API fidelity per service.** Labtris covers the operations
  that map to real primitives; less-common operations return
  `NotImplementedException` with a clear message. This is deliberate:
  we'd rather fail loudly than pretend.
- **Every AWS service.** Storage / DB / serverless services (S3
  behavior aside, since it wraps MinIO) are wrapped via best-of-breed
  OSS — DynamoDB via Scylla Alternator, Lambda via OpenFaaS, RDS via
  Postgres/MySQL containers. Full list at `/docs/cloud-services`.

## What Labtris is uniquely good at compared to LocalStack

- **Real workloads**: your EC2 instance is a real VM with a real kernel
- **Real networks**: your VPC is a real Linux bridge with real packets
- **Real firewalls**: your security groups compile to a real VyOS /
  Palo Alto / Fortinet appliance sitting in path
- **Multi-cloud**: same box also serves `/_azure/`, `/_gcp/`, `/_oci/`
  once those phases land — cross-cloud connectivity works in one lab
- **Programmable data plane**: your instances can attach to a P4/bmv2
  switch, real ECN/PFC/RoCE — try emulating that in LocalStack
